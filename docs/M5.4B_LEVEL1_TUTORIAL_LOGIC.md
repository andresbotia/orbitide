# LEVEL 1 CORE TUTORIAL FLOW

The Level 1 tutorial should guide the player through the complete basic loop with the minimum number of interruptions.

The player should learn through action, not through long text.

Required conceptual sequence:
1. Launch a Pixel Pal from a tunnel.
2. Observe it travel around the rounded perimeter.
3. Observe it attack only a valid front-visible matching pixel.
4. Observe its remaining count decrease after a successful hit.
5. The authored Level 1 setup must allow the Pal to finish a full lap with remaining count > 0.
6. Observe that Pal transition into Holding.
7. Prompt the player once to tap the held Pal.
8. Relaunch the held Pal.
9. Allow the player to finish Level 1.
10. Mark the core tutorial as completed.

The tutorial must NOT become a long sequence of modal dialogs.

---

# TUTORIAL PHILOSOPHY

Use:
- contextual interaction gating
- lightweight tutorial state
- event-driven advancement
- short presentation hooks

Avoid:
- modal-heavy flows
- arbitrary timers for progression
- advancing tutorial state merely because time passed
- duplicating engine truth in tutorial code
- hardcoding visual coordinates
- tutorial logic inside rendering components

Tutorial progression should advance from **real gameplay events/state transitions**.

Examples:
- launch actually accepted
- a valid hit actually resolved
- count actually decreased
- pass actually completed
- charge actually entered Holding
- held charge actually relaunched
- level actually completed

# INTERACTION GATING

Only gate player interaction when it materially helps teach the action.

The tutorial should feel like playing the game, not following a rigid slideshow.

### Initial launch stage
It is acceptable to restrict the player to the intended tunnel for the first launch.

### Observe-hit stage
Do not interrupt movement. Let the gameplay event teach the player.

### Holding stage
Once the Pal enters Holding, guide the player toward the correct held Pal.

### Relaunch stage
It is acceptable to temporarily prevent unrelated launches until the player relaunches that held Pal.

### Free-play stage
Remove tutorial interaction restrictions and let the player finish Level 1 normally.

Do not permanently bake tutorial restrictions into general Core V2 engine rules.
