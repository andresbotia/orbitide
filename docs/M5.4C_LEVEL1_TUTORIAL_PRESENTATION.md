# TUTORIAL FLOW TO PRESENT

The state machine already handles:

`launch`
→ `observeHit`
→ `observeHolding`
→ `relaunchHeld`
→ `freePlay`
→ `completed`

The presentation should visually teach:

1. Tap the intended tunnel to launch.
2. Watch the Pixel Pal travel the rounded perimeter.
3. Watch it hit the first visible matching pixel and decrement its count.
4. Watch the unfinished Pal land in Holding.
5. Tap that held Pal to relaunch it.
6. Then remove tutorial chrome and let the player finish naturally.

No extra tutorial stages.
