# LOCKED CORE V2 RULES

## Targeting
- Pal attacks only the first eligible/front visible matching target on its inward attack line.
- Occupied cells block targets behind them.
- Clearing the front cell does NOT allow immediate drilling through to the newly exposed cell during the same encounter.
- Newly exposed targets require a later valid encounter/pass.

## Lifecycle
- One launch/relaunch = one complete perimeter pass.
- Hits reduce count by 1.
- Count 0 during the pass = consumed.
- Full lap with remaining count > 0 = enters Holding.
- Held Pal can be manually relaunched for another full pass.

## Capacity
- 4 tunnels total.
- queue preview = current / next / next+1 only.
- 4 Holding slots.
- default Active capacity = 5.

## Fairness
- deterministic
- no randomness
- no booster/item required
- no hidden unfair trap
- no special mechanics in Levels 1–10
